# つばさ税理士事務所 Webサイト（修正サンプル）

架空の税理士事務所サイトに対する修正のサンプルです。事務所名・住所・電話番号・人物はすべて架空のものです。

公開ページ: https://mashite792.github.io/tsubasa-tax/

## ご依頼内容

> いつもお世話になっております。つばさ税理士事務所の高橋です。
> ホームページについて、以下の修正をお願いいたします。
>
> 1. 相続税の申告を新しく始めました。業務内容と料金ページに追加してください。料金は330,000円〜です。
> 2. 4月から税理士が1名増えて2名体制になりました。事務所概要の人数を直して、新しい税理士（佐伯 陽菜）の紹介も載せたいです。
> 3. 電話の受付時間を 9:00〜18:00 に延長しました。
> 4. お問い合わせフォームで、電話番号をハイフン付きで入れると「形式が正しくありません」と出て送れない、とお客様から言われました。

## 対応内容

| # | 修正ファイル | 内容 |
|---|---|---|
| 1 | index.html / fee.html | 業務内容に「相続税申告」を追加。料金ページのスポット業務に「相続税申告 330,000円〜」を追加 |
| 2 | index.html / css/style.css | 事務所概要を「税理士 2名」に修正。代表あいさつの下に所属税理士の紹介枠を追加（写真は差し替え用の枠） |
| 3 | index.html / fee.html | 受付時間の表記7か所（ヘッダー・フッター・事務所概要・お問い合わせ）を 9:00〜18:00 に変更 |
| 4 | js/contact.js | 原因：電話番号を「数字のみ」でチェックしていたため、ハイフン入りが弾かれていた。ハイフン・空白・カッコ・全角数字を取り除いてから、0で始まる10〜11桁かを確認するよう修正 |

変更箇所の詳細は[コミット履歴](https://github.com/mashite792/tsubasa-tax/commits/main)から確認できます。
